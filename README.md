# Wiltshire Chess website

Independent static HTML pages for Home, News, Leagues, Clubs, About and History. Shared styles and mobile menu in `assets/site.css` and `assets/site.js`.

Edit each HTML page directly. All links are relative to support GitHub Pages project URLs. Google Sheets content remains placeholder-only for now. Navigation is repeated in each page to avoid a build system; update links across pages when adding pages.
